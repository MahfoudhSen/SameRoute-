🗺️ Google Maps API Setup

Follow these simple steps to get your maps working in 5 minutes!

⚡ Quick Option: Don't want to setup Google Maps? Use the simple test version which works without an API key!
1 Go to Google Cloud Console

Visit the Google Cloud Console and sign in with your Google account:

https://console.cloud.google.com/
Open Google Cloud Console →
2 Create a Project
  1. Click the project dropdown at the top
  2. Click "NEW PROJECT"
  3. Name it: "GreenRoute" (or anything you like)
  4. Click "CREATE"
  5. Wait a few seconds for it to be created
3 Enable Required APIs

In the search bar at the top, search for and enable these 3 APIs:

  1. Maps JavaScript API - Click "Enable"
  2. Places API - Click "Enable"
  3. Geocoding API - Click "Enable"

💡 Tip: Search for each one separately, click on it, then click the blue "Enable" button

4 Create API Key
  1. In the left sidebar, click "Credentials"
  2. Click "+ CREATE CREDENTIALS" at the top
  3. Select "API key"
  4. A popup appears with your API key - COPY IT!

⚠️ Your API key looks like: AIzaSyD...

5 Enter Your API Key Below
6 Test the Live Map!

Your API key has been saved! Now test the live matching system:

🚗 Open Live Matching →
